Surveillance rover with live image processing

A Bluetooth-controlled rover that streams camera frames to a PC for edge detection, stores them in MySQL and serves them on a web portal.

When
2016
Where
VIT
Status
prototype
Best project award for the semester

Problem

One project for the whole semester: a single system that used what we were learning in Computer Vision and Image Processing, Database Systems, Computer Networks, and Probability and Statistics. A surveillance rover touched all four.

What I built

An early-stage prototype of a surveillance rover system, from driving the rover to storing and viewing what it saw.

How it works

  • Drive. An Android app sends driving commands to the rover’s Arduino over Bluetooth.
  • Streaming. Camera frames stream in real time from the rover to a PC.
  • Processing. A MATLAB edge-detection algorithm based on ANOVA runs on the frames.
  • Storage. Frames are saved and indexed in a MySQL database.
  • Viewing. A PHP web portal with sign-in shows the live stream and the stored images.

Results

Won the best project award for the semester at VIT in 2016.
